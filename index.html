TScrambler

Some Twitch streams are scrambled into tiles. Install TScrambler once and they play normally.

1. Install (once)

  1. Download TScrambler for Chrome
    Unzip it.
  2. Open chrome://extensions (copy it into the address bar) and turn on Developer mode, top right.
  3. Click Load unpacked and pick the unzipped folder.
  1. Get Violentmonkey
    Click Add to Firefox.
  2. Install TScrambler
    Click Install on the page that opens.

Also works in any browser with Violentmonkey or Tampermonkey.

2. Watch

Open the stream. The picture fixes itself within a few seconds. Live, VODs, clips and embeds all work.

Streamer gave you a link? Open it once and accept the prompt. TScrambler remembers it for that channel.

Keys

Alt+Shift+STurn descrambling on or off for this channel
Alt+Shift+RShow the scrambled picture
Alt+Shift+HShow or hide the status panel

Not working?

  • Still tiles: the channel uses its own code. Ask the streamer for the current link.
  • Choppy: set the stream quality to Source and turn on hardware acceleration in your browser settings.
  • Ads play normally. Descrambling comes back after them.
  • Still stuck: press Alt+Shift+H and send a screenshot to the streamer.

1. Install

Download for OBS (Windows)

Run it, then restart OBS. Needs OBS 31 or newer, 64-bit Windows.

2. Scenes

  1. Show: your normal scene with everything in it (video, webcam, alerts, chat box).
  2. Broadcast: a new scene with only one source, the Show scene, filling the canvas.
  3. In Broadcast, right-click Show → Filters → add TScrambler: Scramble. Keep it the last filter.
  4. Stream the Broadcast scene.

Never put anything on top of Show in Broadcast: it reaches viewers unscrambled, and TScrambler turns it into garbage for them.

3. Code

Channel default (recommended): type your channel name in the filter. Viewers with TScrambler need nothing else.

Own code, so only people you give it to can watch:

  1. Set Code to Own code and type your channel name.
  2. Pick a pattern and options (below), then click Generate new code.
  3. Click Copy share link and post it where your viewers are (Discord, whispers). They open it once.

A new code means a new scramble: everyone needs the new link.

Patterns

PatternLooks likeQuality cost
Squares16×9 grid of squares (the channel default)Medium
Mixed gridRows and columns of different sizesMedium
BricksRows of different heights, each cut differentlyMedium
Vertical stripes16 full-height stripesLow
Horizontal stripes9 full-width stripesLow
Big blocks8×5 large blocksLow
Giant blocks4×3 huge blocksLowest

Fewer, bigger pieces look better on stream but are easier to undo by eye.

Options

Mirror tilesFlips some tiles
Rotate tilesTurns some tiles
Swap colorsChanges the colors of some tiles; costs a little quality
Change the scramble every N minNew layout every N minutes, same code for viewers. 0 = never.

4. Check

Make a scene Verify with the Broadcast scene in it and add the filter TScrambler: Descramble (verify) with your code (or channel name). It should look like Show. Switch away from it while live; it uses GPU time.

Paste this in your chat once (Nightbot, as a mod or the streamer):
