TScrambler

Unscrambles tiled Twitch streams in your browser. Streamers scramble theirs in OBS.

1Install

Also Brave and Opera

  1. Download for Chromethen unzip it.
  2. Go to chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
  1. Download for Firefoxno need to unzip it.
  2. Go to about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and pick the zip.

Firefox removes it when you close the browser. To keep it, use the userscript.

Any browser

  1. Add Violentmonkey for Firefox, Chrome or Edge.
  2. Install userscriptthen click Install.

Chrome or Edge: open Violentmonkey's Details and turn on Allow user scripts.

2Watch

Open the stream. The picture clears up after a few seconds.

Got a link from the streamer? Open it once and click OK.

1Install

Download for OBSRun it, then restart OBS.

Windows, OBS 31 or newer.

2Scenes

  1. Show: your usual scene with everything in it.
  2. Broadcast: a new scene with only Show in it, full size.
  3. In Broadcast, right-click Show, Filters, add TScrambler: Scramble.
  4. Stream the Broadcast scene.

Don't add anything else to Broadcast. Viewers would see it garbled.

3Code

Channel default Recommended

Type your channel name in the filter. Anyone with TScrambler can watch.

Own code

Pick a pattern and Generate new code. Send viewers the share link.

Patterns

PatternLayoutStream quality
Squares16×9 squaresGood
Mixed gridUneven rows and columnsGood
BricksOffset rowsGood
Vertical stripes16 columnsBetter
Horizontal stripes9 rowsBetter
Big blocks8×5 blocksBetter
Giant blocks4×3 blocksBest

Bigger pieces look better on stream but are easier to undo by eye.

Options

Mirror tilesFlips some tiles
Rotate tilesTurns some tiles
Swap colorsRecolors some tiles, costs a little quality
Change every N minNew layout, same code. 0 is off.

4Check

Make a scene with Broadcast in it and add TScrambler: Descramble (verify) with your code. It should look like Show.

Switch away from it while live. It uses GPU time.
